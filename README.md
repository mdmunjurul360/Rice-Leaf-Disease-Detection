# 🌾 Rice Leaf Disease Detection and Treatment Recommendation System

An intelligent Rice Leaf Disease Detection and Treatment Recommendation System developed as a **Final Year Thesis Project** for the **Bachelor of Science (B.Sc.) in Software Engineering**.

The system aims to identify common rice leaf diseases from leaf images using **Machine Learning** and provide treatment recommendations through a modern web-based application.

> **Project Status:** Academic Thesis Project (Under Active Development)

---

## 📌 Overview

Rice diseases significantly affect crop production and food security. This project explores the application of Machine Learning for automatic rice leaf disease detection and provides treatment recommendations to assist farmers.

This repository contains:

- Modern React frontend
- FastAPI backend
- Trained TensorFlow/Keras model
- Disease information and treatment recommendation system

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/mdmunjurul360/Rice-Leaf-Disease-Detection.git

cd Rice-Leaf-Disease-Detection
```

---

## Frontend

```bash
cd frontend

npm install

npm run dev
```

---

## Backend

```bash
cd backend

pip install -r requirements.txt

uvicorn app.main:app --reload
```

---

# 🧠 Machine Learning Model

The trained TensorFlow/Keras model is stored inside the repository and is used by the backend during prediction.

Model Framework:

- TensorFlow
- Keras

The backend automatically loads the trained model during application startup.

---

# 📸 Dataset

The model was trained using publicly available rice leaf disease images collected for academic research purposes.

Dataset preprocessing and model training were performed using **Google Colab**.

> **Note:** The dataset itself is not included in this repository.
